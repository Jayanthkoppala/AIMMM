                               AGENT DETAILS

┌─────────────────────────────────────────────────────────────────────────┐
│ 1. MARKET DATA AGENT                                                     │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  strategy_config, pool_id                                        │
│ Output: market_data, data_complete, data_errors                         │
│ Tools:  ohlcv_service, technical_indicators, sentiment_analyzer         │
│ Time:   ~0.5s                                                           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 2. PORTFOLIO AGENT                                                       │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  strategy_id, strategy_config, market_data                       │
│ Output: portfolio_state, active_positions, usdc_balance                 │
│ Tools:  paper_trading_dex                                               │
│ Time:   ~0.3s                                                           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 3. MONITORING AGENT                                                      │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  strategy_id, strategy_config, pool_address                      │
│ Output: exit_positions, should_exit_positions                           │
│ Tools:  paper_trading_dex.check_exit_signals                           │
│ Time:   ~0.2s                                                           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 4. RISK AGENT                                                            │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  strategy_id, strategy_config, portfolio_state, decision         │
│ Output: risk_checks, risk_warnings, risk_approved                       │
│ Tools:  paper_trading_dex, risk_management                             │
│ Time:   ~0.1s                                                           │
│ Checks:                                                                  │
│   - Position limits (max concurrent)                                    │
│   - Capital availability                                                │
│   - Confidence threshold (>= 0.70)                                      │
│   - Gas efficiency                                                      │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 5. ANALYSIS AGENT                                                        │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  market_data, portfolio_state                                    │
│ Output: analysis, trend_analysis, market_conditions                     │
│ Tools:  Data parsing and interpretation                                 │
│ Time:   ~0.2s                                                           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 6. DECISION AGENT                                                        │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  portfolio_state, market_data, strategy_config, analysis         │
│ Output: decision, confidence, action, reasoning                         │
│ Tools:  llm.get_strategy_decision (OpenRouter)                         │
│ Time:   ~1-3s (LLM call)                                                │
│ Actions: BUY, SELL, HOLD, CLOSE_POSITION                               │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 7. EXECUTION AGENT                                                       │
├─────────────────────────────────────────────────────────────────────────┤
│ Input:  strategy_id, decision, market_data, risk_approved               │
│ Output: trade_result, should_execute_trade                              │
│ Tools:  paper_trading_dex, mosaic (swap quotes)                        │
│ Time:   ~0.5s                                                           │
│ Handles:                                                                 │
│   - BUY orders (get quote, execute swap)                                │
│   - SELL orders (get balance, execute swap)                             │
│   - Exit positions (stop-loss/take-profit)                              │
└─────────────────────────────────────────────────────────────────────────┘


================================================================================
                            STATE FLOW EXAMPLE
================================================================================

Example successful BUY execution:

1. START: strategy_id, user_id, strategy_config
   └─> TradingState created with initial values

2. MARKET DATA AGENT
   └─> market_data: {ohlcv, technical, sentiment, price}
   └─> data_complete: true

3. PORTFOLIO AGENT
   └─> portfolio_state: {total_value: $1000, usdc: $1000}
   └─> active_positions: []

4. MONITORING AGENT
   └─> exit_positions: []
   └─> should_exit_positions: false

5. RISK AGENT (Preliminary)
   └─> risk_checks: {position_limit: true, sufficient_capital: true}
   └─> risk_approved: true

6. ANALYSIS AGENT
   └─> trend_analysis: "Upward trend detected"
   └─> market_conditions: "Technical indicators lean bullish"

7. DECISION AGENT
   └─> decision: {action: "BUY", confidence: 0.85, token: "MOVE", amount: $100}

8. RISK AGENT (Final)
   └─> risk_checks: {confidence: true, position_limit: true, capital: true, gas: true}
   └─> risk_approved: true

9. EXECUTION AGENT
   └─> trade_result: {executed: true, side: "buy", amount_in: $100, amount_out: 50 MOVE}

10. END
    └─> Response with decision, trading_state, trade_executed: true


================================================================================
                              ERROR HANDLING
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│ SCENARIO 1: Market Data Incomplete                                      │
├─────────────────────────────────────────────────────────────────────────┤
│ Market Data Agent → data_complete: false                                │
│                  → Retry (up to 3 times)                                │
│                  → Still incomplete? → Continue with available data     │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SCENARIO 2: Risk Check Failed                                           │
├─────────────────────────────────────────────────────────────────────────┤
│ Risk Agent → risk_approved: false                                       │
│           → Route to END                                                │
│           → Return HOLD decision                                        │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SCENARIO 3: LLM Error                                                    │
├─────────────────────────────────────────────────────────────────────────┤
│ Decision Agent → LLM call fails                                         │
│               → Fallback: action: "HOLD", confidence: 0.3              │
│               → Log error in state                                      │
│               → Continue to Risk Agent (will reject)                    │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ SCENARIO 4: Execution Error                                             │
├─────────────────────────────────────────────────────────────────────────┤
│ Execution Agent → Swap fails                                            │
│                 → trade_result: null                                    │
│                 → Log error                                             │
│                 → Return gracefully (no crash)                          │
└─────────────────────────────────────────────────────────────────────────┘
